# PROJECT REQUIREMENTS: PERSONAL LANGUAGE LEARNING PLATFORM

## 1. Project Overview

Build a modern, interactive, personalized language-learning web
application that allows the user to study two languages simultaneously:

-   **English:** Current level B1 (Intermediate) → Target level B2
    (Upper-Intermediate).
-   **Japanese:** Complete beginner (zero knowledge) → Target JLPT N5,
    with a foundation for N4.

The platform should function as a complete self-learning ecosystem, not
just a static educational website.

It must provide: - Structured learning roadmaps. - Theory and
explanations. - Practical exercises and quizzes. - Listening, speaking,
reading, and writing practice. - Vocabulary and grammar learning. -
Progress tracking and performance evaluation. - Personalized revision
and learning recommendations. - Gamification to encourage consistent
learning.

Use Vietnamese as the primary language for instructions and
explanations, while English and Japanese are used as learning materials.

## 2. Design Direction & Visual Reference

Use the attached Manae website screenshot as the primary visual
reference.

Do not copy the interface exactly. Adapt its visual language into a
polished, modern language-learning platform.

### Visual characteristics

**Overall style** - Minimalist, modern, friendly, and playful. - Clean
educational dashboard. - Soft pastel colors combined with strong black
and white contrast. - Rounded cards and pill-shaped buttons. - Subtle
shadows and delicate borders. - Generous whitespace. - Clear typography
hierarchy.

**Color palette** - Primary background: warm white / off-white. -
Navigation header: deep black (`#08090D`). - English learning: soft
pastel blue. - Japanese learning: soft pastel lavender / purple. -
Completed activities: soft pastel green. - Vocabulary: pastel yellow. -
Listening and speaking: pastel pink. - Neutral cards: light gray.

Avoid excessive gradients, neon colors, unnecessary animations, and
overly corporate dashboard aesthetics.

### Layout

**Top navigation** - Brand logo and application name. - Home. - Learning
Roadmap. - Vocabulary. - Practice. - Notes / Learning Resources. - Daily
streak. - XP points. - Current learning level and progress.

**Left navigation** - Compact icon-based sidebar. - Expandable menu. -
Notifications. - Settings.

**Main dashboard** - Personalized greeting. - Daily learning
recommendation. - Overall learning progress. - English and Japanese
learning journey cards. - Upcoming lessons. - Daily learning tasks.

**Right panel** - Today's learning schedule. - Daily goals. - Vocabulary
review reminders. - Upcoming lessons. - Learning streak and
achievements.

Use the screenshot's visual composition as inspiration: a large central
learning area and a secondary right-hand panel.

## 3. Main Application Structure

### A. Home Dashboard

The homepage should provide an overview of both language-learning
journeys.

**Welcome section** - Personalized greeting. - Today's learning
objective. - Current learning streak. - Recommended learning activity.

**Learning overview**

Create two prominent language cards.

**ENGLISH** - Current level: B1. - Target: B2. - Overall completion
percentage. - Completed lessons. - Remaining lessons. - Current learning
module. - Continue learning button.

**JAPANESE** - Current level: Beginner. - Target: JLPT N5. - Overall
completion percentage. - Completed lessons. - Remaining lessons. -
Current learning module. - Continue learning button.

**Today's Learning Plan**

Display a daily checklist containing: - English lesson. - Japanese
lesson. - Vocabulary revision. - Listening practice. - Short quiz.

Allow users to mark activities as completed.

**Learning statistics** - Total study time. - Lessons completed. -
Vocabulary learned. - Quiz accuracy. - Weekly learning consistency.

### B. Learning Roadmap

Create a visual learning journey inspired by Manae's roadmap design.

Each language must have an independent learning roadmap.

Lessons should appear as connected cards along a visual progression
path.

Each lesson card should contain: - Lesson title. - Learning objective. -
Short description. - Estimated study time. - Lesson status: Locked /
Available / In Progress / Completed. - Learning activity indicators.

Use different pastel colors for different types of lessons.

Users should be able to click an available lesson and enter its learning
interface.

Completed lessons should visually change to indicate progress.

Locked lessons should become accessible when their prerequisites are
completed.

Allow users to view upcoming modules and their learning objectives.

## 4. English Learning Curriculum: B1 → B2

Design a structured English curriculum based on CEFR standards.
Gradually develop all four language skills.

### Module 1: Strengthening B1 Foundations

Topics: - Tenses review and practical usage. - Present Perfect vs Past
Simple. - Past Perfect. - Future forms. - Modal verbs. - Conditionals. -
Passive voice. - Relative clauses. - Reported speech. - Comparatives and
superlatives.

Skills: - Understanding everyday conversations. - Describing personal
experiences. - Expressing opinions. - Writing coherent paragraphs.

### Module 2: Expanding B1 Vocabulary

Topics: - Work and career. - Education. - Technology and AI. - Lifestyle
and wellbeing. - Travel and culture. - Environment. - Society and
communication.

Include: - Topic-based vocabulary. - Collocations. - Phrasal verbs. -
Common idioms. - Word formation. - Synonyms and antonyms.

### Module 3: Developing B2 Grammar

Topics: - Advanced conditionals. - Mixed conditionals. - Advanced
passive structures. - Inversion. - Cleft sentences. - Advanced modal
verbs. - Complex sentence structures. - Linking words and discourse
markers. - Advanced relative clauses.

### Module 4: Reading Comprehension

Practice with: - News articles. - Blog posts. - Workplace documents. -
Opinion articles. - Academic-style texts. - Long-form passages.

Question types: - Main idea. - Specific information. - Inference. -
Vocabulary in context. - Writer's opinion and purpose.

### Module 5: Listening Comprehension

Practice with: - Everyday conversations. - Workplace meetings. -
Interviews. - Podcasts. - News reports. - Different English accents.

Exercises: - Multiple choice. - Fill in the blanks. - True / False. -
Dictation. - Listen and summarize.

### Module 6: Speaking

Practice: - Introducing yourself professionally. - Expressing
opinions. - Discussing abstract topics. - Describing experiences. -
Giving presentations. - Participating in discussions. - Explaining and
defending ideas.

Provide speaking prompts, sample answers, useful expressions, and
self-assessment criteria.

### Module 7: Writing

Practice: - Emails. - Formal and informal messages. - Opinion
paragraphs. - Essays. - Reports. - Arguments and recommendations.

Evaluate: - Grammar. - Vocabulary range. - Coherence. - Organization. -
Task achievement.

### Module 8: B2 Assessment

Include: - Reading tests. - Listening tests. - Grammar and vocabulary
tests. - Writing assignments. - Speaking assessments.

Provide a final assessment report showing strengths, weaknesses, and
skills that need improvement.

## 5. Japanese Learning Curriculum: Beginner → JLPT N5

Create a beginner-friendly Japanese curriculum that assumes absolutely
no prior knowledge. Teach Japanese progressively, with explanations in
Vietnamese.

### Module 1: Hiragana

Learn all 46 basic Hiragana characters.

Include: - Character recognition. - Pronunciation. - Stroke order. -
Writing practice. - Listening recognition. - Reading simple words.

### Module 2: Katakana

Learn all 46 basic Katakana characters.

Include: - Character recognition. - Pronunciation. - Writing practice. -
Foreign loanwords. - Katakana reading exercises.

### Module 3: Japanese Pronunciation

Topics: - Japanese vowel sounds. - Long vowels. - Double consonants. -
Small や・ゆ・よ. - Dakuten and handakuten. - Basic pronunciation rules.

### Module 4: Basic Vocabulary

Topics: - Numbers. - Dates and time. - Greetings. - Family. - People. -
Food and drinks. - Places. - Transportation. - Daily activities. -
Shopping. - School and work.

Each vocabulary item must contain: - Japanese characters. - Hiragana
reading. - Romaji. - Vietnamese meaning. - Audio pronunciation when
available. - Example sentence.

### Module 5: Basic Grammar

Topics: - A は B です. - これ / それ / あれ. - この / その / あの. -
ここ / そこ / あそこ. - Particles は, が, を, に, で, へ, の, も. - ます
and ません forms. - あります and います. - Adjectives い and な. - Basic
question sentences. - Past tense. - Negative forms. - Basic verb
conjugation.

Every grammar lesson should include: 1. Explanation in Vietnamese. 2.
Sentence structure. 3. Japanese examples. 4. Romaji. 5. Vietnamese
translations. 6. Common mistakes. 7. Practice exercises.

### Module 6: Everyday Conversations

Topics: - Introducing yourself. - Greeting people. - Ordering food. -
Asking for directions. - Shopping. - Talking about family. - Talking
about hobbies. - Talking about daily routines.

Include conversation simulations and role-playing exercises.

### Module 7: Kanji Introduction

Introduce basic N5 Kanji progressively.

For each Kanji: - Character. - Meaning. - On'yomi. - Kun'yomi. - Stroke
order. - Common vocabulary. - Example sentences.

Do not overload beginners with too many Kanji at once.

### Module 8: JLPT N5 Preparation

Include: - Vocabulary quizzes. - Kanji recognition. - Grammar
exercises. - Reading comprehension. - Listening comprehension. - Timed
practice tests.

Provide a final N5 readiness assessment.

## 6. Interactive Learning Experience

Every lesson must have a consistent learning structure.

### Lesson interface

Organize each lesson into five steps.

**Step 1: Learn** - Introduce the lesson topic. - Explain concepts
clearly. - Show examples. - Highlight important information.

**Step 2: Understand** - Short comprehension questions. - Match words
with meanings. - Identify grammar structures.

**Step 3: Practice** - Multiple-choice questions. - Fill in the
blanks. - Sentence construction. - Word matching. - Translation
exercises. - Listening exercises when applicable.

**Step 4: Apply** - Real-life scenarios. - Short writing assignments. -
Speaking prompts. - Conversation practice.

**Step 5: Evaluate** - Display results. - Explain correct and incorrect
answers. - Identify weak areas. - Recommend revision activities.

Users must be able to revisit previous lessons.

### Exercise types

Implement interactive exercise components: 1. Multiple choice. 2. Fill
in the blank. 3. Drag and drop. 4. Word matching. 5. Sentence ordering.
6. Flashcards. 7. True / False. 8. Listening comprehension. 9.
Translation. 10. Writing assignments. 11. Speaking practice.

All interactive exercises must provide immediate feedback.

Do not only display questions and static answer options. Implement real
answer validation and scoring.

## 7. Vocabulary Management

Create a centralized vocabulary management system. Separate vocabulary
into English and Japanese.

Features: - Save new words. - Add words from lessons. - Create custom
vocabulary lists. - Search words. - Filter by topic. - Mark words as
difficult. - Mark words as mastered. - Review previously learned
vocabulary.

### Spaced Repetition System

Implement a review system based on spaced repetition.

Vocabulary should have the following states: - New. - Learning. -
Reviewing. - Mastered.

Automatically recommend words for revision based on previous performance
and review history.

Include flashcard modes: - Show word → Guess meaning. - Show meaning →
Guess word. - Listening → Identify word. - Japanese character → Identify
pronunciation and meaning.

## 8. Learning Evaluation & Analytics

The system must track actual learning performance.

Track the following metrics independently for each language: - Lessons
completed. - Learning time. - Vocabulary acquired. - Quiz accuracy. -
Reading performance. - Listening performance. - Writing performance. -
Speaking performance. - Revision consistency.

Display visual charts: - Weekly learning time. - Monthly learning
progress. - Quiz score trends. - Skill performance comparison. -
Vocabulary growth.

### Personalized feedback

After every quiz or assessment, provide: - Score. - Correct answers. -
Incorrect answers. - Explanations. - Identified weaknesses. - Suggested
lessons to review.

Do not determine proficiency based solely on the number of completed
lessons. Use assessment performance to estimate learning progress.

## 9. Gamification

Use a friendly gamification system inspired by the reference design.

Include: - XP points. - Daily streak. - Learning levels. - Achievement
badges. - Daily missions. - Weekly goals. - Progress milestones.

Examples: - First Lesson Completed. - 7-Day Learning Streak. - 100
English Words Learned. - Hiragana Master. - First Japanese
Conversation. - B1 Grammar Master.

XP should be awarded based on actual completed learning activities.

Avoid excessive gamification that distracts from learning.

## 10. Daily Learning Planner

Create a personalized daily study planner.

Users should be able to: - Set daily study goals. - Allocate time
between English and Japanese. - Select preferred learning activities. -
Track completed tasks. - Reschedule unfinished activities.

Default suggested daily routine: - English: 25 minutes. - Japanese: 20
minutes. - Vocabulary review: 10 minutes.

Total: 55 minutes per day.

This schedule must be editable. Display the daily plan on the homepage.

## 11. AI Learning Assistant

Create an AI learning assistant interface. The assistant should support
both languages independently.

**English Assistant** - Explain grammar. - Correct sentences. - Suggest
more natural expressions. - Evaluate writing. - Generate conversation
scenarios. - Explain vocabulary in context.

**Japanese Assistant** - Explain grammar in Vietnamese. - Explain Kanji
and vocabulary. - Correct basic Japanese sentences. - Explain
particles. - Generate beginner-level conversations. - Provide
pronunciation guidance.

The assistant must adapt explanations to the user's actual level.

Important: - Do not pretend that AI capabilities work without an actual
AI integration. - If no API is configured, provide a functional demo
with sample interactions and clearly indicate the integration point. -
Keep the architecture ready for future AI API integration.

## 12. Technical & Functional Requirements

Build an actual working web application.

Before development: 1. Inspect the existing project structure. 2.
Identify the current framework and dependencies. 3. Reuse the existing
architecture where appropriate. 4. Do not overwrite existing project
files unnecessarily. 5. Plan the component structure before
implementation.

Technical requirements: - Responsive desktop, tablet, and mobile
layouts. - Reusable UI components. - Consistent design tokens. - Clean
component architecture. - Functional navigation. - Persistent user
learning progress. - Search and filtering. - Working quizzes and
scoring. - Working vocabulary management. - Progress tracking. - Data
persistence using an appropriate storage solution.

For the initial MVP, local storage or IndexedDB can be used to persist
user progress without requiring a backend.

Organize learning content in structured data files so lessons can be
expanded and edited easily.

Do not use placeholder buttons that do nothing.

Do not display fake progress or fabricated assessment results.

Provide empty states, loading states, success states, and error states.

## 14. Development Priorities

Build the application in the following order.

**Phase 1 -- Core Foundation** - Design system. - Navigation. - Home
dashboard. - English and Japanese learning roadmaps. - Lesson structure.

**Phase 2 -- Learning Functionality** - Lesson content. - Interactive
exercises. - Quiz evaluation. - Vocabulary management. - Flashcards.

**Phase 3 -- Progress Tracking** - Learning statistics. - Daily
planner. - XP and streaks. - Revision recommendations.

**Phase 4 -- Advanced Features** - AI learning assistant integration. -
Speaking and pronunciation practice. - Advanced analytics. - JLPT N5 and
CEFR B2 assessments.

Prioritize a complete, usable learning experience over building many
empty pages.

## 15. Final Quality Requirements

The final application should feel like a premium personal learning
platform.

It should be: - Visually close to the attached Manae reference. - Easy
to navigate. - Educationally structured. - Interactive. - Consistent
across English and Japanese. - Suitable for long-term self-study.

The most important requirement is that the platform must help the user
progress from English B1 to B2 and Japanese beginner to JLPT N5 through
structured learning, practical exercises, continuous assessment, and
personalized revision.

**Do not stop after generating a homepage mockup. Build the actual
application with functional learning flows and persistent progress.**
